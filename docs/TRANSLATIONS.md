# Названия действий / Control labels

Проверен каталог штатного редактора Li Auto 8.28.3 для панели из четырёх действий. Список не расширяется функциями других моделей.

| Исходная подпись | Русский | English | Смысл |
| --- | --- | --- | --- |
| 车锁 | Замки | Locks | Управление замками |
| 空调 | Климат | Climate | Управление климатом |
| 尾门 | Багажник | Tailgate | Дверь багажника |
| 直线召唤 | Движение | Move | Дистанционное движение вперёд и назад |
| 授权驾驶 | Доступ к вождению | Drive access | Разрешение на вождение |
| 车窗 | Окна | Windows | Управление окнами |
| 寻车 | Найти авто | Find car | Поиск автомобиля |
| 方向盘加热 | Обогрев руля | Steering heat | Обогрев рулевого колеса |
| 除雪除冰 | Разморозка | Defrost | Удаление снега и льда |

Для длинных подписей предусмотрены две строки. Описания для специальных возможностей раскрывают действие полностью. «Вызов авто» не используется: он мог бы подразумевать самостоятельный подъезд к владельцу.

Дополнительно переведены подтверждение, отпирание, обновление, известные сообщения входа/ошибок, время зарядки и возраст данных. Пользовательское имя автомобиля не переводится. Неизвестные сообщения источника сохраняются как получены, чтобы не скрыть реальную ошибку.

Штатный редактор Li Auto и другие экраны оригинального приложения этим компаньоном не переводятся.
