# Проверка релиза Li Widget 1.0

Проверка относится к компаньону dev.li.widget. Оригинальный APK Li Auto не изменялся и не включён в релиз.

## Публичный релиз: сборка 18

Версия **1.0**, `versionCode` **18**, Android 12+ / target API 36. Подпись сохранена от предыдущего релиза.

- Исправлена потеря пиктограмм электричества и топлива в компактном 4×2. В сборке 17 две ImageSpan исчезали при сериализации; отдельные ImageView сборки 18 остаются видимыми после Parcel и повторного применения RemoteViews.
- Пройдены **82 нативные отрисовки**. Базовые 48 покрывают семь форматов, RU/EN, светлую/тёмную темы, минимальные размеры с масштабом шрифта 1.3, состояния зарядки, отключённые действия и подтверждения. Дополнительные 34 проверяют исправленные взаимодействия и размеры.
- В прикреплённом окне Android проверены реальные события касания: вся информационная карточка вызывает только исходный тестовый обработчик обновления; углы кнопки настроек вызывают только настройки. Доступная область кнопки настроек не меньше **48×48 dp**, включая «Зарядку» 250×110 dp.
- После исправления компактной шапки продолжают работать исходные обработчики имени автомобиля, обновления и настроек. Четыре действия в обоих избранных также сохранены. В тесте все обработчики локальные; реальные команды автомобилю не отправлялись.
- Отключённое источником обновление не срабатывает. При отсутствии исходного обработчика собственная команда не создаётся. Повторное применение RemoteViews не дублирует элементы.
- В настоящем MainActivity проверены настройки всех семи форматов: «Подписи кнопок» есть только у универсального, большого и двух избранных. Приложение не записывало новые параметры оформления в ходе этой проверки.
- Все семь провайдеров зарегистрированы и привязаны в Android AppWidgetHost; минимальные размеры, начальные и каталожные макеты проверены. Временные виджеты теста удалены.
- По **204 строки** каждого языка; проверены совпадение ключей/параметров, XML, ссылки, граница приватных данных, состав APK, подпись и выравнивание. Тестовый код и ключ подписи в публикуемый APK и исходники не включены.

SHA-256 APK: `5444e7628a5a905a241ed200d9de75f8ac6ba784f1e4f3e0cf798afedf1677ec`.

SHA-256 сертификата: `8059d47d6463e65219722718ad63e64f1d985641d08b0500e5bdd0278ce8629c`.

Среда: Android 16 / API 36, x86_64, эмулятор, Pixel Launcher. Показания на снимках синтетические. Физические телефоны, другие лаунчеры, фактический ответ автомобиля на обновление и расход батареи отдельно не измерялись. Получение и перевод времени зарядки сохранены.

## Предыдущий публичный релиз: сборка 17

- Видимая версия **1.0**, `versionCode` **17**, `minSdk` 31, `targetSdk` 36. Подпись совпадает с прежними сборками.
- Android регистрирует **семь провайдеров** с отдельными размерами: универсальный, большой, минимальный, запас хода, два избранных и зарядка. Все привязаны через настоящий `AppWidgetHost`; их RemoteViews и начальные/каталожные макеты успешно применены.
- **48 нативных отрисовок**: RU/EN, светлая/тёмная темы, семь форматов, минимальные размеры с масштабом шрифта 1.3, подтверждения, отключённые действия и состояния зарядки. Проверены границы элементов и повторное применение без дублирования строк.
- Во всех сочетаниях языка и темы обеих панелей избранного доставлены четыре исходных тестовых `PendingIntent`. Обработчики в тесте локальные; команды автомобилю не отправлялись.
- Через интерфейс установленного APK открыты все семь типов. Выбор «Избранное 2×2» вызвал системный диалог Android с размером 2×2. Тип закреплён за провайдером уже добавленного экземпляра.
- Процент зарядки не выдаётся за километры; скрытые или отсутствующие значения запаса хода отображаются прочерком. Перевод исходного времени зарядки сохранён; отдельного расчёта нет. Повторный снимок не запускает пульсацию заново.
- В редакторе тестовые значения явно помечены как образец. На рабочем столе без источника отображается приглашение подключить Li Auto.
- По **203 строки** в RU/EN, совпадающие ключи и параметры. Сборка, подпись, выравнивание, XML, локальные ссылки, разрешения, экспорты и состав APK проверены. В APK нет инструментальных тестов, приватных маркеров и Java debug metadata; единственное растровое изображение приложения — документированный атлас аватаров проекта.
- Проверка исходников и релизных файлов не обнаружила встроенных аккаунтов, VIN, секретов или личных путей. Локальные ключи и пароли исключены. На POSIX локальная сборка ограничивает доступ к каталогу ключа и его файлам; символьные ссылки для этих файлов отклоняются.

SHA-256 APK: `19ba4151a78a32a861e2eb3e587341140dd2f0e03c57a797055234146d7ad44c`.

SHA-256 сертификата подписи: `8059d47d6463e65219722718ad63e64f1d985641d08b0500e5bdd0278ce8629c`.

[Нативные изображения и размеры](WIDGETS.md). Показания на новых снимках синтетические, без данных владельца. Проверки выполнялись на Android 16 / API 36, x86_64, Pixel Launcher. На физических смартфонах, Android 12–15 и во всех сторонних лаунчерах эта сборка не проверена. Число ячеек зависит от сетки лаунчера.

При длительных прогонах эмулятор с 2 ГБ памяти и 2 ядрами показывал ANR на фоне системной нагрузки. После перезапуска с 4 ГБ и 4 ядрами меню отвечало; финальный APK открыл Activity за 1,435 с. Это наблюдение о тестовой среде, а не замер производительности или расхода батареи на телефоне.

## Предыдущий публичный релиз: сборка 9

- Видимая версия **1.0**, `versionCode` **9**, `minSdk` 31, `targetSdk` 36.
- Собственный значок приложения, уведомления и заглушки; нативный предпросмотр меню виджетов с собственной векторной графикой. Извлечённые изображения Li Auto исключены из исходников и APK.
- Пройдены **64 проверки** нативных RemoteViews: RU/EN, день/ночь, ширина 250/352 dp, масштаб шрифта 1.0/1.3; предпросмотр и заглушки высотой 110/160/244 dp. Подписи помещаются, перевод присутствует, многоточия нет. Исправлено обрезание текста подключения при увеличенном шрифте.
- Обновление установленной сборки 8 до 9 успешно: привязка Li Auto, виджет на главном экране, русский язык и выбранное оформление сохранены.
- По **142 строки** для RU/EN; ключи и форматные параметры совпадают.
- Пройдены сборка, проверка подписи и выравнивания, проверка состава APK, исходников и ссылок документации. Публикуемый APK не содержит тестовых классов, Java debug metadata, растровых ресурсов и ключей.
- Добавлена CI-проверка сборки без доступа к ключу публикуемого APK. Она не проверяет управление автомобилем.

Тесты выполнялись без аккаунта владельца и без реального автомобиля. Изображения в README — рендеринг собственного предпросмотра, прочерки не являются телеметрией.

## Исправление цвета багажника: сборка 8

В исходном Li Auto провайдер меняет пару значков багажника в зависимости от варианта автомобиля. Для неактивного ic_widget_mxi_tail_off в сборке 7 не применялся цвет выбранной темы. Он добавлен в перечень неактивных значков, которым назначается общий цвет кнопок. Исходные формы значков, состояния открытия и обработчики нажатий сохранены.

- До исправления ошибка воспроизведена на исходном ресурсе ic_widget_mxi_tail_off.
- После исправления пройдены 64 комбинации: две исходные пары значков, обычное/активное состояние, четыре темы, системная/нейтральная палитра, дневной/ночной режим.
- Проверено равенство цвета неактивного багажника цвету соседней кнопки и сохранение исходной окраски активного состояния. Растровая форма исходного значка не изменяется.
- Подписанный APK успешно обновил установленную версию 1.0 (7) до 1.0 (8); привязка оригинального виджета и экземпляр на главном экране сохранены.
- Повторно пройдены проверки сборки, подписи, выравнивания APK и состава релизных файлов.

## Чистота релиза

Проведён просмотр Java-кода, manifest, ресурсов, сценария сборки и документов. Дополнительно проверены строки DEX, содержимое APK/ZIP, локализованные ресурсы, разрешения, сертификат и отсутствие текстовых/EXIF-метаданных PNG.

Не обнаружены встроенные персональные аккаунты, VIN, ФИО/контакты автора, личные ссылки, пути рабочей машины или секреты. Публичные ссылки ведут на страницы проекта GitHub. В APK отсутствуют отладочное логирование и тестовые классы. Архив исходников формируется из проверенного Git-коммита и не включает .local/, ключи, пароли, кэш, декомпилированный оригинал и тестовые данные.

В manifest нет разрешений на интернет, Bluetooth, геолокацию, контакты и хранилище. Служба и приёмники приватные. Экспортирована только Activity входа/настройки; переданный идентификатор виджета проверяется на принадлежность нашему провайдеру. Источник проверяется по пакету и классу штатного провайдера.

## Пределы проверки

Автомобиль и аккаунт владельца к тестовому эмулятору не подключены. Выполнение реальных команд L7/L-серии и серверная доступность не проверялись. Обработчики команд остаются в Li Auto. Числа в инструментальных тестах синтетические. Образец редактора без подключения явно помечен; виджет на рабочем столе не подменяет отсутствующие данные образцом.

Инструментальные проверки выполнялись на Android 16 / API 36 и Pixel Launcher. Android 12–15 и другие лаунчеры отдельно не проверялись.

Полный аудит безопасности оригинального Li Auto не проводился. Совместимость привязана к проверенной структуре его виджета в версии 8.28.3. Непредусмотренные сообщения источника могут остаться на его языке.

Измеренная температура салона через текущую связь не поступает; результат исследования описан в [CABIN-TEMPERATURE.md](CABIN-TEMPERATURE.md).

## English summary

Current public release: **1.0, build 18**, signed with the existing release certificate. **82 native renders** passed, including RU/EN, light/dark and minimum dimensions with larger system text. Attached-window touch events verified original refresh callbacks, independent 48×48 dp settings targets including Charging at minimum height, and the original compact header handlers. The electricity/fuel ImageViews survive Parcel/reapply. Disabled and missing-refresh cases were checked. The production settings UI hides button-label sizing in all three formats without a control panel. All seven providers were registered and bound by Android, and both languages contain 204 matching resource keys.

The checks used synthetic source readings and local dummy callbacks on Android API 36. No real vehicle command was sent. The release checks, signing certificate and alignment passed. Physical phones, other launchers, vehicle response and battery usage were not tested separately for this build. Charging-time interpretation remains unchanged.


Previous public release: **1.0, build 17**, Android API 31+, targeting API 36, with the existing signing certificate. All seven Android providers were registered and bound in a real `AppWidgetHost`. Their initial/picker layouts applied successfully. **48 native rendering checks** covered RU/EN, light/dark, minimum dimensions with font scale 1.3, confirmation/disabled states and charging. All four original test action handlers were delivered in both favorites layouts; no real vehicle command was sent. The installed production UI exposed all seven formats and opened Android's 2×2 pin dialog for Favorites.

Both languages have 203 matching resource keys. Signature, alignment, source/privacy boundary, XML, links and APK-content checks passed. Test classes, credentials, private keys and Java debug metadata are excluded. The app includes its documented generated avatar atlas. Release source and downloadable archives exclude private build inputs. Charging-time interpretation is unchanged; missing/hidden range values remain unavailable, and unconnected samples are explicitly labelled.

Tests used Android 16 / API 36, Pixel Launcher, without an owner account or a connected car. Other Android versions, physical phones and launchers have not been separately validated for this build. CI confirms buildability, not vehicle-command compatibility. A long-running 2 GB emulator exhibited ANR during system pressure; a fresh 4 GB run completed the app flows. No phone performance or battery-life claim is made. The original Li Auto app has not undergone a full security audit as part of this work.

Earlier build results above are retained as historical evidence. The new native images in [WIDGETS.md](WIDGETS.md) show synthetic readings, not owner data.
